## 🌟 About Odyssey Community - [Join now](odyssey-invite)

Odyssey is a self-development and self-learning community founded in 2023.

- Over 50 blog posts on a variety of topics, including experiences, knowledge, fables, books, movies, and more - all aimed at supporting learning and personal growth.
- Provided life guidance and support to more than 30 individuals.
- A thriving community of over 200 members, with more than 20 actively engaging every day.
- An average of 150 hours of dedicated learning per month.

As a small community, we support each other, striving to become more diligent, intelligent, and happier every single day.

<br/>

> "The Odyssey of life is full of challenges; it's a blessing that we have each other."
> — Nguyễn Thành Duy

## 🚀 Getting Started

### Prerequisters

- pnpm

```sh
npm install pnpm@latest -g
```

### Installation

1. Give me a star
2. Clone the repo

```sh
git clone https://github.com/NguyenThanhDuyOfficial/odysseyv2
cd odysseyv2
```

3. Install packages

```sh
pnpm install
```

4. Docker Postgres

```sh
systemctl start docker && docker compose up
```

5. Run the dev

```sh
pnpm dev
```

## 🤝 Contributing

This project is open-sourced because I believe it would be wonderful if more communities like Odyssey could flourish around the world.

Contributions are what make the open source community such an amazing place to learn, inspire, and create. Any contributions you make are **greatly appreciated**.

If you have a suggestion that would make this better, please fork the repo and create a pull request. You can also simply open an issue with the tag "enhancement".
Don't forget to give the project a star! Thanks again!

1. Fork the Project
2. Create your Feature Branch (`git checkout -b feat/AmazingFeature`)
3. Commit your Changes (`git commit -m 'feat: add some amazingfeature'`)
4. Push to the Branch (`git push origin feat/AmazingFeature`)
5. Open a Pull Request
